# Baseline Project MotoFlash Express

Baseline for project Moto Flash Express

## Description

Moto Flash Express is a technology platform designed to revolutionize motorcycle delivery services in the Ameca region and its surrounding areas. Unlike traditional informal services, MotoFlash combines the agility of motorcycle transportation with a formalized business model focused on trust, speed, and transparency.

## Stack (Suggest Technology)

* **Frontend:** App React / React Native (Web/Androi).

* **Backend:** Node.js whith Express.

* **Data Base:** PostgreSQL.

* **Geolocation:** Integration with Google Maps Platform.
