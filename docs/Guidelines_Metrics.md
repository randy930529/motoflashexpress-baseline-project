# Guidelines & Measurement
To ensure objective evaluation of each change or decision, the following guidelines and metrics are defined:

## Assessment factors

| Factor                 | Scale                                       | Application  |
|------------------------|---------------------------------------------|------------------------------|
| Effort (Fibonacci)     | 1, 2, 3, 5, 8, 13, 21                       | Junior: simple tasks (1–2). Semi-senior: module integration (3–5). Senior: architecture and audits (8–13). Validated in planning meetings. |
| Budget Impact (%)      | Low <10%, Medium 10–25%, High >25%          | Managers and finance calculate increments. Example: hiring external specialist = medium (10–25%). 10% reserve applied. |
| Time (weeks)           | Short ≤2, Medium 3–6, Long >6               | Junior: ≤2 weeks. Semi-senior: 3–6 weeks. Senior: >6 weeks. Timelines adjusted and documented. |
| Human Resources        | 0, 1-2, 3-5, >5                             | HR determines recruitment needs. Example: 1–2 specialists for security. |
| Contracts              | Required / Not Required                     | Legal validates agreements with providers and banks. |
| Technological Resource | Existing, minor expansion, major expansion  | Infrastructure classifies expansions. Example: cloud migration = major expansion. |
| Required Skills        | Available, minor training, external hiring  | Training tailored: basic (junior), advanced (semi-senior), certifications (senior). |
| Project Stage          | Initiation, development, testing, operation | Managers document progress at each stage. |
| Legal Obligations      | Yes / No                                    | Legal applies a compliance checklist at each delivery. |

## Application process
1. Each change request will be evaluated against these factors.
2. A value will be assigned according to the defined scale.
3. Results will be documented in the impact matrix.
4. The control board will use this information to decide approval or rejection.

## Associated risks
- Underestimation of effort: Mitigation: peer review.
- Unexpected budget increase: Mitigation: 10% reserve.
- Lack of required skills: Mitigation: early training.
- Omitted legal obligations: Mitigation: mandatory compliance checklist.
